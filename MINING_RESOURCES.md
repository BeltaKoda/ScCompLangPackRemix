## Notes

- **"Aluminum" vs "Aluminium"**: Planet descriptions use "Aluminum" (Hurston, Arial, Aberdeen, Magda), the compendium uses "Aluminium" (Cellin, Yela). Listed as separate entries since CIG wrote them differently.
- **"Alumium" (Ita)**: This is a CIG typo in the planet description -- likely intended as "Aluminum."
- **"Tarantite" vs "Taranite"**: Planet descriptions for Cellin and Yela use "Tarantite," the compendium uses "Taranite." Listed separately as they may be distinct resources.
- **"Quantainium"**: Correct in-game spelling used consistently in both planet descriptions and compendium.
- **"Ariel" (compendium)**: The compendium spells it "Ariel" for the Quartz entry -- the moon is actually "Arial." Preserved as CIG wrote it.
- **Janalite vs Janalite (Caves only)**: Planet descriptions distinguish between locations where Janalite appears on the surface and locations where it is caves-only. The compendium lists specific locations without the caves qualifier. Both entries are kept separate.
- **New in 4.7.0**: Aslarite, Ouratite, Stileron, Sadaryx added. Savrilium and Torite now also list QV Breaker Stations (Nyx). Quasigrazer now appears on Hurston.

## Legend

- **Ship Mineable** -- Requires a mining-equipped ship (Prospector, MOLE, etc.)
- **Ship Mineable (Rare)** -- Ship mineable but spawns infrequently
- **Ship Mineable (Rare, Pyro Only)** -- Rare, only found in the Pyro system
- **Hand Mineable** -- Can be mined with a multitool + mining attachment
- **Ground Vehicle Mineable** -- Requires a ground mining vehicle (e.g., ROC)
- **Harvestable** -- Collected by hand, no tools required
- **Creature** -- Fauna encountered at the location

## Data Source

All data extracted from `global.ini` localization file:
- **Planet/moon descriptions** -- StarMap description fields (e.g., `Stanton1a_Desc`, `Pyro1_desc`)
- **Mining Compendium** -- `Journal_General_Mining_Compendium_Content` (in-game journal by United Resource Workers)
